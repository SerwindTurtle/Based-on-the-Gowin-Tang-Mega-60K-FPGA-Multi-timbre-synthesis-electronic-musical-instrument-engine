演奏效果

实时生效

延音踏板：松开琴键后不立刻掐断，而是按「延音」滑块慢慢衰减。 0 = 保持原来的释音；越大尾音越长。钢琴/古筝/木琴默认关；颠琴/钟琴默认开（40）。 切到持续音会自动关闭并禁用滑块；手动改过延音后保持到下一次切音色。 ADSR 里的「延音电平 S」是按住时的电平，和这个踏板不是一回事。

单音：所有键共用一条声部，后按的键实时接管音高、不重触发包络；配合滑音就是滑音变调。 颤音/滑音在单音模式下最自然（复音模式下每个键固定一条声部，滑音不明显）。

32 声部齐奏 / 超锯齿

8 键 × 4 层 = 32 个振荡器；附加层共用每键的包络/力度，所以不需要 32 套 ADSR。
齐奏 Unison

主声部是第 1 层；附加层是微失谐锯齿。想听纯 supersaw，请把音色选到「锯齿」再开齐奏。 层数 4 = 每键 4 层 = 8 键共 32 个振荡器；层数 2/3 分别是 16/24 个。

PWM 脉宽调制

只作用在「方波」音色；锯齿/三角/正弦/FM 不受影响。深度 0 = 固定脉宽。

PWM 让方波的占空比随 LFO 摆动，听感比固定方波更“活”。只作用方波：动 PWM 时会自动切到方波；深度拉到 0 就是固定脉宽。

串口在哪里？

    

      板上标着 DEBUG-USB2 的那个 USB-C 口（就是下载码流用的那个，
      不是 USB3.0 那两个）。板载 BL616 同时提供 JTAG + UART，
      会枚举出两个 COM 口：A 通道 = JTAG、B 通道 = UART——
      用 B 通道那个（本机实测 A=COM5 / B=COM6）。
      不需要外接 CH340 模块。
    

    

      如果一定要用外接 CH340：不能并在 U15/V14 上（会和 BL616 抢线），
      只能把 src/fpga_project.cst 里的 UART_TX / UART_RX
      改到 40P 排针上的两个空闲 3.3V IO，重新综合布线。

演奏效果怎么用

    
    
      
  • 颤音：全局 LFO 调制音高，速率 0.5~12Hz，深度约 ±0~±104 音分。
    • 
      
  • 滑音：新音高不直接跳过去，而是按“时间常数”慢慢逼近；在单音模式下最明显。
    • 
      
  • 单音：8 个键共用一条声部，后按的键实时接管音高，只要还有键按着就不重触发包络——
        配合滑音就是“实时滑音变调”。
    • 
      
  • 实时变调：整体移调 ±12 半音；按住音再拖它，配合滑音会滑过去。
    • 
      
  • 八度偏移：±2 个八度，和板上 KBD_UP / KBD_DN 是同一个状态，会互相跟随。
    • 
      
  • 延音（松开后）：像钢琴延音踏板，松手后声音不立刻消失，而是慢慢衰减。
        0 = 关闭（原释音）；越大尾音越长。只对钢琴/古筝/木琴/颠琴/钟琴（one-shot）有效：
        钢琴/古筝/木琴切过去默认关，颠琴/钟琴默认开（40）；切到持续音会自动关闭并禁用滑块。
        ADSR 的 S 是按住时的电平，不是这个踏板。
    • 
    


    
混音台 / 效果器 / EQ 怎么用

    
    
      
  • 32 个声部：1–8 对应 8 个琴键，默认展开；9–32 是预留声部，默认折叠，
        点「全部展开」可以提前设好参数。
    • 
      
  • 每通道：音量、失真，以及回声/混响/合唱/相位 4 路发送量（0–15）。
        发送量只决定这个声部送多少到全局效果器；发送量从 0 拉高会自动打开对应效果器。
    • 
      
  • 效果器：回声（延时/反馈/返回量）、混响（空间/阻尼/返回量）、
        合唱（速率/深度/返回量）、相位（速率/深度/反馈/返回量）。
    • 
      
  • 自定义音色：手动改波形/FM/ADSR/泛音/单次包络会自动进入「自定义」档；
        再点任意预设或按板上 KEY0 退出。
    • 
      
  • PWM 脉宽调制：基础脉宽/速率/深度，只作用在方波音色；动 PWM 会自动切到方波。
    • 
      
  • 颠琴 / 钟琴：两个 FM 音色，都是 one-shot，所以延音踏板对它们有效。
    • 
      
  • 监视器：网页波形/频谱是参数预览；HDMI 顶部是真实音频的 4 段频谱（8 条）。
    • 
      
  • 失真 / 限幅：主失真（驱动/音色/混合）和限幅器（阈值/天花板/软拐点）。
    • 
      
  • 32 声部齐奏：8 键 × 4 层 = 32 个振荡器；附加 3 层是微失谐锯齿，
        共用每键包络/力度。默认开；层数 1~4、失谐量、混合量可调。
    • 
      
  • 均衡器：5 段（低频/中低/中频/中高/高频），每段 −24~+12dB，另有 EQ 输出。
    • 
    


    
协议（115200 8N1）

    
A5 5A | TYPE | LEN | PAYLOAD | CRC8(poly 0x07)
01 SET   N × {addr, val_lo, val_hi}   N≤16
02 GET   N × {addr}
03 PING
81 VALUE / 82 TELEM(16B, 24Hz) / 83 PONG
