# Tang Mega 60K 压力感应演奏合成器

把 PMOD 排针上的一路模拟电压（0~3.3V，以后接压力传感器）转成数字量，经 **滤波 + 稳定**，
翻译成 **音符事件（音高/力度/开关）**，分配到 **N 个独立声部（当前 32）**，每个声部跑
**振荡器 + 独立 ADSR**，再经 **通道条（音量/失真/4 路发送）+ 全局效果器（回声/混响/合唱/相位）
+ 5 段均衡 + 限幅 + 主音量** 合成一路，最后：

- **I2S 输出** → 板载 PT8211 DAC → NS4263 功放 → 耳机 / 扬声器
- **LCD 显示** → 1024×600 IPS 屏，显示音频波形 + 复音数 + 键盘按键状态

按键 **KEY0** 可运行时切换 **10 档硬件音色**（网页另有第 11 档「自定义」）：方波 / 锯齿 / 三角 / 正弦（持续音）
+ **钢琴 / 古筝 / 木琴 / 单簧管 / 颠琴 / 钟琴**。板上 `KBD_UP` / `KBD_DN` 和网页都能改八度（±2）。

## ★ 图形化控制台（2026-10-26 新增：串口 + 网页）

现在所有音色/包络/混音参数都是 **FPGA 内部的运行时寄存器**，

```

   ▼
板上 DEBUG-USB2 的 USB-C 口 —— 板载 BL616（USB-JTAG & UART）
```

  包络速率/指数衰减、`MIX_SHIFT`、主音量/静音、8 个键各自的音量；
  新增 **演奏效果**：颤音（速率/深度）、滑音（时间）、单音模式（连奏实时变调）、
  实时变调（±12 半音）、**八度偏移（±2，和板上八度键同步）**、

  9–32 声部默认折叠；拉高发送量会自动打开对应效果器）、**4 个全局发送式效果器**、
  **主失真**、**主限幅**、**5 段均衡器**、**32 声部齐奏/超锯齿（8 键 × 4 层）**；

## 三、模块详解

### 3.1 `adc_ctrl.v` ADC 控制器

状态机：`S_IDLE` → `S_TRIG`（`adc_start=1`）→ `S_WAIT`（等 `adc_ready`）→ 锁存 `adcvalue[13:0]`，
输出 `adc_data[13:0]` 和 `adc_valid`。

> `adcvalue` 是**有符号数**。电压模式下 **实际电压 ≈ adcvalue / 2048**，所以 3.3V 约为 6758。

### 3.2 `adc_filter.v` 滤波 + 稳定

| 参数 | 默认 | 含义 |
|------|------|------|
| `AVG_BITS` | 4 | 滑动平均窗口 `2^4 = 16` 个采样 |
| `STABLE_TH` | 8 | 判定"稳定"的滞回阈值 |
| `STABLE_BITS` | 1 | 稳定判定需要的连续次数 `2^1 = 2` |
| `FAST_TH` | 64 | 差值超过它就快速跟随（提高响应速度） |

总延迟 ≈ `2^AVG_BITS × 2^STABLE_BITS` 次 ADC 转换。

### 3.3 `note_gen.v` 电压 → 音符

| 参数 | 默认 | 含义 |
|------|------|------|
| `GATE_TH` | 100 | 超过这个值算"按下" |
| `VAL_LO / VAL_HI` | 0 / 6758 | 对应的 0V / 3.3V 码值 |
| `NOTE_LO / NOTE_HI` | 48 / 72 | 映射到 MIDI 48~72（C3~C5，两个八度） |
| `MULT / SHIFT` | 233 / 16 | 换算系数 |
| `VEL_FIX` | 100 | 力度固定值（以后接压力传感器再改成动态） |
| `REL_CNT` | 16 | 松开后多久算 note_off |

公式：`note = NOTE_LO + ((value - VAL_LO) * MULT) >> SHIFT`

其中 `MULT = 2^SHIFT × (NOTE_HI - NOTE_LO) / (VAL_HI - VAL_LO)`。

### 3.4 `voice_alloc.v` 声部分配

- `note_on` → 找**编号最小的空闲声部**
- 全满 → **偷掉** `cur_voice` 那个声部
- `note_off` → 释放该声部
- 同一音符再次触发 → 只更新音高（legato）

`NUM_VOICES` 在 `top.v` 里，现在设为 **32**。
`voice_alloc` / `voice_meter` / `lcd_draw` 的位宽都会**自动跟着变**，
改这一个数字就够了。

| 配置 | 全设计 LUT/ALU | DSP | BSRAM |
|------|---------------|-----|-------|
| **当前：8 个琴键 + 32 振荡器齐奏 + 效果链** | **44771 / 59904（74.7%）** | **约 108.5 / 118（92%）** | **34 / 118** |
| 纯振荡器（不含效果链，历史参考） | 8 声部 ≈ 30% / 32 声部 ≈ 40% | 8 声部 23% / 32 声部 ~85% | — |

> ⚠️ 32 声部时 DSP 比较紧。若综合报 DSP 不够，把 `NUM_VOICES` 调回 16 或 8 即可。
> 2026-10-26 第三轮把混音/效果/EQ 加进来之后 LUT 从 30% 涨到 60%，主要来自
> 8 路通道条和 4 个效果器的移位加法；DSP 仍有余量。
> （正弦表已改写成"65 点四分之一波 + 象限镜像"，等效 256 点但省 3~4 倍资源。）

### 3.5 `adsr.v` 独立 ADSR

`gate` 上升沿 → Attack；下降沿 → Release。模块本身只有一套状态机，
**两套"音色性格"是靠在 `top.v` 里喂不同参数（含 `rate` 速率分频）配出来的**（见下表）。

| 参数 | 含义 | 持续音（方波/锯齿/三角/正弦） | 钢琴音色 |
|------|------|------------------------------|---------|
| `env_rate` | **包络速率分频** | 0（每个采样点更新，最快） | **2（每 4 拍更新一次）** |
| `atk_step` | 起音步长 | 67（≈ 20 ms） | **1074（≈ 5 ms，干脆的琴槌感）** |
| `dec_step` | 衰减步长 | 7（≈ 190 ms） | **1（≈ 5.4 s，按住时慢慢淡出）** |
| `sus_level` | 延音电平 | 45874（≈ 70%，按住不衰减） | **0（没有延音平台）** |
| `rel_step` | 释音步长 | 4（≈ 335 ms，松手后自然收尾） | **4096（≈ 1.3 ms，松手瞬间掐断）** |

**钢琴包络的窍门**：把"延音电平设成 0"+"衰减拉长"，状态机就会在按住期间
一路衰减到静音（D → S，而 S 就是 0），得到一个按下即衰减的打击乐包络；
再把释音步长拉到很大，松手时几乎立刻归零。**不需要改状态机结构。**

#### ⚠️ 时间换算（这里以前写错过，务必按下面的公式）

16 位包络的范围是 0 ~ 65535，**起音和衰减/释音的方向不同，但分母都是满量程**：

```
有效采样率 = 48828.125 Hz / 2^env_rate

起音时间 ≈ 65536 / (atk_step × 有效采样率)
衰减时间 ≈ 65535 / (dec_step × 有效采样率)
释音时间 ≈ 65535 / (rel_step × 有效采样率)

反推步长：步长 ≈ 65536 / (目标秒数 × 有效采样率)
```

> **关键限制**：`env_rate = 0` 时步长最小是 1，所以 16 位包络在 48kHz 下
> **最长的衰减/释音就是 65535 / 48828 ≈ 1.34 秒**，光调参数到不了几秒。
> 想要几秒的钢琴尾音，必须用 `env_rate` 把有效采样率降下来
> （`env_rate = 2` → 有效 12207Hz → 单步最长 5.37 秒）。

> ⚠️ `env_rate` 会**同时**放慢起音/衰减/释音，改它的时候三个步长要一起重算。

### 3.6 `osc_voice.v` 单声部振荡器

相位累加器 (NCO)，相位增量 `inc = base_inc[半音] << (八度 - 5)`。

`base_inc[]` 是 note 60~71（C4~B4）的相位增量，按
`inc = 音频率 × 2^24 / 采样率` 算出来，采样率 = **3.125MHz / 64 = 48828.125 Hz**。

> ⚠️ **换采样率必须重算 `base_inc[]`**（改 `top.v` 的 `SAMPLE_DIV` 时别忘了）。

**当前 10 个硬件音色**，用板载 **KEY0** 或网页「音色设计」切换；网页另有「自定义」档：

| 档位 | 音色 | 波形实现 | 包络 |
|------|------|---------|------|
| 0 | 方波 | 24 位相位高 8 位 + PWM 占空比 | 持续音 |
| 1 | 锯齿 | 相位高 16 位偏移二进制（**上电默认**） | 持续音 |
| 2 | 三角 | 相位高 16 位折叠 | 持续音 |
| 3 | 正弦 | 256 点查表 | 持续音 |
| 4 | 钢琴 | 固定正弦 + 加法泛音 | one-shot |
| 5 | 古筝 | FM ratio 1.0 | one-shot |
| 6 | 木琴 | FM ratio 3.5 | one-shot |
| 7 | 单簧管 | FM ratio 2.0 | 持续音 |
| 8 | 颠琴 | FM ratio 2.0，短促 | one-shot |
| 9 | 钟琴 | FM ratio 3.5，明亮 | one-shot |

每按一下 KEY0 顺序循环 0→1→…→9→0，带 **21ms 去抖**。LED 只显示低 3 位，
所以 8/9 档会分别显示成 `000`/`001`；网页上仍显示真实的 8/9。

**PWM** 只作用在方波：`duty = PWM_WIDTH + LFO`，幅度/速率/深度由 `0x2D`~`0x2F` 控制；
深度 0 时是固定脉宽。网页有独立卡片。

**PCM 输出**：`pcm = 波形 × 包络 × 力度`（16 位有符号）。

| 模块 | 作用 | 资源要点 |
|---|---|---|
| `fx_channel_mix` | 每通道音量（0~128）、失真（预增益+软削波+干湿）、4 路发送量（0~15） | 全部用移位/加法，不占 DSP；只处理前 8 个声部 |
| `fx_echo` | 16384 点延时线（10.5~324ms）+ 4 位反馈 + 湿声返回 | 约 15 块 BSRAM |
| `fx_reverb` | 4 梳状（带阻尼）+ 2 全通 | 约 10 块 BSRAM |
| `fx_mod` | 合唱（≈14ms 调制延时）+ 相位（≈4ms 短延时+反馈） | 2 块 BSRAM，2 个乘法器 |
| `fx_master` | 主失真 → 5 段 EQ → 软限幅 → 主音量 5ms 平滑 | 5 段 EQ 的增益乘法用移位实现 |

- **每通道效果是“发送量”**：4 路发送汇入 4 个全局效果器，湿声在 `fx_master` 里与干声相加。
  32 套独立延时线资源放不下，专业调音台也是这个结构。
- **5 段 EQ**：低频 <120Hz、中低 120–500Hz、中频 0.5–1k、中高 1–5k、高频 >5k；
  分频点固定，每段增益 −24~+12dB（寄存器 1/16 线性，16 = 0dB）。
- **限幅**：阈值/天花板/软拐点可调，输出饱和到 16 位，防止回绕爆音。
- **主音量/静音** 仍然走 5ms 斜坡，不会咔哒；效果尾音在松手后继续响（不再用硬 gate 掐断）。

> 资源实测（综合）：LUT/ALU 44771 / 59904（74.7%）、BSRAM 34/118、DSP 约 108.5/118（92%）。
> 32 声部齐奏由 `unison_saw.v` 实现：8 键 × 4 层，附加 3 层共用主声部 env/vel，
> 只多 24 个相位累加器 + 16 个 DSP；详细寄存器见 `web/README.md` 第四节。

### 3.8 `i2s_tx.v` PT8211 音频输出

**板上音频链路**（Dock 原理图 `DAC+PA` 页）：

```
FPGA ──I2S──▶ U16 PT8211-S(立体声DAC) ──▶ U17/U18 LMV321 低通 ──▶ U20 NS4263 功放 ──▶ 耳机/扬声器
```

| 信号 | 引脚 | 说明 |
|------|------|------|
| `HP_BCK` | Y17 | BCK = 50MHz / 32 = **1.5625 MHz** |
| `HP_WS` | AB17 | 声道时钟，**高 = 左，低 = 右** |
| `HP_DIN` | AA16 | 数据：二进制补码、MSB 先出、下降沿变化、DAC 上升沿采样 |
| `PA_EN` | AB16 | 功放使能，**低有效**：`0` = 开功放 |

一帧 = 32 个 BCK → **采样率 = 48828.125 Hz**

**⚠️ PT8211 不是标准 Philips I2S！**

| 项目 | 标准 I2S | **PT8211** |
|------|---------|-----------|
| WS 极性 | 低 = 左 | **高 = 左，低 = 右（相反）** |
| MSB 位置 | WS 边沿后延迟 1 个 BCK | **就在 WS 边沿（无延迟）** |
| 每帧 BCK 数 | 64 | **32**（每声道 16 位） |

时序要点：**BCK 下降沿更新 WS/DIN，上升沿由 DAC 采样**，这样才有半个周期的建立时间。

> ✅ PT8211 **免配置**（芯片上没有任何 I2C 引脚），不需要初始化模块。
>
> ⚠️ 采样率 48828Hz 比标准 48kHz 高 **1.7%**（音高略偏高）—— 50MHz 晶振无法整数
> 分频出 48kHz。要精确 48kHz 需换晶振或用 PLL 产生 12.288MHz。

### 3.9 `scope_capture.v` + `voice_meter.v`

- **`scope_capture`**：环形缓冲存最近 **1024 个采样**（≈21ms，440Hz 约 9 个周期），
  提供读端口给绘制逻辑

**屏**：5 寸 IPS，**1024×600**，RGB(TTL) **RGB666**（板上每通道只接高 6 位），
40pin FPC 接板子 **`J5`** 座；触摸是 **GT911 电容触摸**，走独立的 6pin 排线接 **`J6`** 座。

### 🔴 两个曾经导致"背光亮但全黑"的根因（已修复，别再踩）

排查了十几轮之后，最终由独立的 `LCD_test` 工程逐根核对原理图定位到：

#### 根因 1：三个控制脚的球号接错了

之前照抄了 Sipeed **相机例程**的 `.cst`，那三个网名看着像、其实不是 LCD 的线：

| 面板信号 | 板上网名 | **正确球号** | 之前用的（❌ 实际是） |
|---|---|---|---|
| DCLK | `HTACK` | **L19** | J20（那是 HRCLK） |
| HSYNC | `HTREQ` | **N20** | J21（那是 HRACK） |
| VSYNC | `HTVLD` | **L15** | G18（那是 HRVLD） |

**接错的后果：面板一个时钟都收不到 → 背光亮、屏全黑、而且改任何时序参数都无效。**

> 顺带纠正一个流传很久的误判：**L19 不是"只能做输入的 I²C 专用脚"**。
> 它确实带 `SDA` 复用功能（`IOR61[A]`），但只要工程配置里把 I2C 那组
> 设成可当普通 IO（综合配置里 `"I2C": true`），
> 它就能当**输出**用 —— 面板的 DCLK 恰恰就在这根线上，实测布线通过。
> 而**红色 R5 接的是 `HTRDY = J22`（普通 IO，能驱动）**，
> 所以之前"红色只有 4 位、满量程只有 85%"的说法是**错的**，
> 现在用的是完整的 **RGB666（18 位）**。

#### 根因 2：CH569 在抢同一组总线 ★

面板的**每一根**信号线都同时挂在板上的 **CH569W（U12）** 上：

| 面板信号 | 板上网名 | CH569 的脚 |
|---|---|---|
| DCLK | `HTACK` | `PA10` |
| HSYNC | `HTREQ` | `PA9` |
| VSYNC | `HTVLD` | `PA21` |
| DEN | `HD2` | `PA22` |
| 18 根颜色线 | `HD4 HD3 HTRDY HD1 HD0 HRVLD` / `HD10..HD5` / `HCTS HD15..HD11` | `PB0`~`PB15` |

CH569 一上电就去驱动这些脚，和 FPGA 对打 —— 最要命的是 **DCLK 线被两个输出源
同时驱动**，面板拿到的是被搅烂的时钟，于是**什么都不显示、只剩背光**。

**★ 永久解决办法：短接板上的 3pin 跳线 `J17` 的 1–2 脚**

```
   J17-1 = +3V3 ──┐
   J17-2 = CH569_EN ├── Q9 (SI2301, P-MOS) ──► CH569 的 3.3V 供电
   J17-3 = GND   ──┘         R36 100K 把 CH569_EN 默认拉到 GND
```

| J17 | `CH569_EN` | Q9 | CH569 | 结果 |
|---|---|---|---|---|
| 不插（默认） | 0V | 导通 | **供电** | ❌ 抢总线 → 屏全黑 |
| **短接 1–2** | +3V3 | 关断 | **断电** | ✅ 总线让给 LCD → 出图 |

> 代价：CH569 的 USB3 功能同时没了 —— 这本来就是**二选一**
> （用了 LCD 就不能同时用 CH569）。插上跳线 = 用 LCD；拔掉 = 用 CH569。

**实测验证**：按住板上 CH569 的电源键（SW6）时屏立刻出图，松开又黑。

#### 顺带：「背光亮」什么都不能说明

原理图上背光驱动 LP3320 的 EN 被 **R47（20.5K）上拉到 +3.3V**，
**只要板子一上电背光就是亮的**，跟 FPGA 跑没跑、屏有没有收到信号都无关。
判断 FPGA 到底跑没跑，要看 **LEDs** 有没有变化。

**为什么不存整帧**：

| 项目 | 容量 |
|------|------|
| GW5AT-60 BSRAM | 约 **265 KB** |
| 1024×600 RGB565 整帧 | **1.2 MB** ❌ |

所以**不做帧缓存，逐像素实时生成**，BSRAM 只用采样缓冲那一小块（4096×16bit）。

**画面布局**（`TOP_H = 62`）：

```
y   0.. 27   复音条形图 + 当前复音数 + 峰值复音数
y  30.. 59   ★ 键盘行：8 格音名（C4 D4 E4 F4 G4 A4 B4 C5），按下的格子变亮
y  62..599   波形区：中间一条基准线 + 混音波形（绿）
```

**时序参数**（`lcd_timing.v` / `top.v` 例化，换屏就改这里）：

| 参数 | 当前值 | 说明 |
|------|--------|------|
| `H_ACTIVE` | 1024 | 有效像素 |
| `H_FP / H_SYNC / H_BP` | 24 / 136 / 160 | 水平前肩 / 同步宽度 / 后肩 |
| `V_ACTIVE` | 600 | 有效行 |
| `V_FP / V_SYNC / V_BP` | 3 / 6 / 29 | 垂直前肩 / 同步宽度 / 后肩 |
| `HSYNC_LOW / VSYNC_LOW` | 1 / 1 | 同步极性（低有效） |

- Htotal = 1344，Vtotal = 638
- **像素时钟 = `sys_clk` = 50MHz 直驱**（不分频、不加 PLL）
  → 刷新率 ≈ **58.3 Hz**（60Hz 需要 51.2MHz，为它加 PLL 不划算）
- ⚠️ 若画面出现撕裂/噪点，说明 50MHz 超了面板上限：
  把 `top.v` 里 `wire pclk = sys_clk;` 改回 `sys_clk/2`（25MHz），
  但刷新率会掉到约 29Hz，会比较闪

#### ⚠️ 改分辨率/改像素时钟后，SDC 必须同步改（踩过坑）

工程里有一个 **`src/fpga_project.sdc`** 声明两个真实时钟：

```tcl
create_clock -name sys_clk  -period 20  -waveform {0 10}  [get_ports {sys_clk}]
create_clock -name adc_clk  -period 320 -waveform {0 160} [get_nets {clkdiv_cnt[3]}]
```

**没有这个文件时**，工具不会给任何时钟建约束（日志里只有
`WARN (TA1132) ... was not created`），PnR 的优化目标和设计真实频率对不上，
表现为**布线阶段无限拖延**（实测卡过 9 分钟到 27 分钟）。加上 SDC 后布线收敛到 1 分钟级。

> 改 `SAMPLE_DIV`（音频采样率）时要同步改 `adc_clk` 的周期：
> `周期(ns) = 320 × (原分频 / 新分频)`。
> 改像素时钟（比如加 PLL）时，要把 `sys_clk` 那条换成对应的 `create_clock`。

原理图 LCD_DPI 页的 J5（FPC-40P）实际接线**不是常规 RGB565 接法**：

| 8 R3 | `HD0` | 红 R3 |

| 10 R5 | `HTRDY` | ⚠️ 见下方说明 |
| 11 R6 | `HD3` | 红 R6 |

| 5,6 R0,R1 | GND | 红低位接地 |
| 13,14 G0,G1 | GND | 绿低位接地 |

### 3.11 `keyboard_in.v` 钢琴键盘输入（★ 8 键 = 一个八度，已预留接口）

> **状态：接口已写好并验证可综合，但默认是关闭的**（还没接线）。

`src/keyboard_in.v` 把 N 个按键引脚变成"每键一份"的音符事件，
直接打包成 `synth_voices` 需要的格式。两条核心规则：

**① 位映射（音高）**：`note_out[i*7 +: 7] = NOTE_BASE + (N-1-i)`

即 **`KBD[0]` 发这一排里最高的音，`KBD[7]` 发最低的**，
这样按键从左到右正好对应音阶从低到高。接线反了就把例化里的
`.REVERSE(1'b0)`（顶层的 `KBD_REVERSE`）改掉。

**② 固定声部映射**：第 i 个键固定占用**第 i 个声部**。

- 好处：多键同时按下时**各自独立发声、独立衰减，互不打断**
  （钢琴本来就该这样：低音可以一直按着余音，同时弹高音）
- 代价：同时能响的键数 = 声部数（`NUM_VOICES=32` 时 8 键绰绰有余）
- 因为声部号固定，"同一键重复按下"必然伴随 gate 的 0→1 上升沿，
  振荡器和包络都会正确重新触发

默认音阶（C4~C5 大调，钢琴上正好一个八度的白键）：

| 键 | `KBD[7]` | `KBD[6]` | `KBD[5]` | `KBD[4]` | `KBD[3]` | `KBD[2]` | `KBD[1]` | `KBD[0]` |
|----|---------|---------|---------|---------|---------|---------|---------|---------|
| 音 | C4 (60) | D4 (62) | E4 (64) | F4 (65) | G4 (67) | A4 (69) | B4 (71) | **C5 (72)** |

去抖 ≈ `2^15 / 3.125MHz ≈ 10.5ms`（参数 `DBNC_BITS`）。

#### 怎么启用（两步，缺一不可）

1. **`top.v`**：把 `KBD_ENABLE` 从 `1'b0` 改成 **`1'b1`**
2. **`fpga_project.cst`**：把 `KBD[0]`~`KBD[7]` 那 8 条 `IO_LOC/IO_PORT`
   取消注释，**并把 `BTN` 那条注释掉**（BTN 占着 AA20，和键盘抢同一个脚）

> ⚠️ **球号必须自己核对**：cst 里那段模板默认整段注释掉，
> 里面只有 6 个"确认过能用"的 PMOD 脚，另外 2 个留成 `??` 待定。
> 其中 `Y21`/`Y22` 还被 ADC 占位端口 `adc_ain_p/n` 占用，
> 要用得先给它们另找两个 ADC 脚。详见 cst 里的说明。
>
> ⚠️ 极性沿用实测结论：按键**松开 0V / 按下 3.3V（高有效）**，
> 所以 cst 模板里用 `PULL_MODE=DOWN` 兜底（没接键盘时读 0，不会误触发）。

#### 只接 1~2 个键先试？

可以。未接的键记得在 cst 里也约束上（`PULL_MODE=DOWN`），
悬空的输入脚读 0 就不会触发。想临时少接几个也能直接把 `KBD` 端口位宽改小，
但记得同步改 `keyboard_in` 的 `NKEYS`。

#### 接好线怎么调试（屏幕上有键盘行）

LCD 顶部新增了一整行"键盘显示"（`TOP_H` 从 48 扩到 **62**）：

```
y  0..27   复音条形图 + 当前/峰值复音数（原来就有）
y 30..59   ★ 键盘行：8 格，每格显示按键对应的音名
y 62..599  波形区（基线相应下移）
```

- 每格显示音名（如 `C5` / `D4`），**按下时格子变亮青色、文字变白**
- 接线时不用再猜：哪个键没反应、哪个键接错了位置，一眼就能看出来
- 显示的音名来自 `lcd_draw` 的 `KBD_NOTE_LO / KBD_REVERSE` 参数，
  **这两个参数必须和 `top.v` 里的同名配置保持一致**，否则屏幕显示的
  音名会和实际发声不一致（代码里已经用顶层参数传进去了，不用手改两处）

#### ★ 力度 / 压力传感器预留

现在力度是固定值（`KBD_VEL` = 100）。压力传感器到了之后：

1. `top.v` 里把 **`KBD_VEL_SRC` 从 `1'b0` 改成 `1'b1`**
2. 力度就改由 ADC 读数决定，映射公式：

```
力度 = clamp((ADC - VEL_MIN) / (VEL_MAX - VEL_MIN) × 127, 0, 127)
      VEL_MIN = 200   （死区，防止零点抖动）
      VEL_MAX = 8000  （满力度点；想"按满就到 127"就调小到约 3600）
```

代码里用"取高 7 位"近似除法，够用且不占乘法器。想更精确可以在 `top.v` 里换成乘法。

> ⚠️ 打开前先确认 ADC 真能读到传感器（`adc_ain_p` 现在占的是 Y21，
> 而且 ADC IP 的 bus 配置可能对不上）——读不到就会一直是 0 力度。
> 排查办法见第七节"ADC 相关"。

> 注意：打开 `KBD_VEL_SRC` 后，**所有声部共用同一个力度值**（当前 ADC 读数）。
> 按键的"力度"就是按下的那一刻或者说当时压力大小；
> 如果一个键按住时压力变了想实时改变音量（触后 aftertouch），
> 那需要把 velocity 改成"每个声部实时跟着自己的传感器走"，属于下一步的工作。

| `LCD_CTP[1]` | **U16** | 普通 3.3V IO |
| `LCD_CTP[2]` | **T16** | 普通 3.3V IO（也是 ADC bus0 唯一能碰到的脚） |
| `LCD_CTP[3]` | **T15** | 普通 3.3V IO |

> ⚠️ **RST / INT / SDA / SCL 四根线到 `LCD_CTP[0..3]` 的具体对应顺序还没核实**。
> 板子原理图是 KiCad 导出的、文字全是矢量线条，没法自动搜索网名。
> 屏到手后按下面任一办法确认：
> 1. 看 J6 座附近的**丝印**
> 2. 量一下哪两根有**上拉电阻**（典型 4.7k 到 3.3V）——那两根就是 SDA/SCL
> 3. 实在分不清就两个方向都试一遍：写个 I²C 扫描，能在某个地址收到 ACK 的那组就是对的
>    （GT911 的 I²C 地址是 `0x5D` 或 `0x14`，由上电时 INT 脚电平决定）

**软件要做的**（还没写）：

1. **I²C 主机**（纯 FPGA，开漏 + 上拉；100kHz 够用）
2. **GT911 初始化 + 读坐标**（写配置寄存器，然后周期读坐标寄存器）
3. **触摸坐标 → 音色按钮判定**，接到现有的 `timbre_sel`
4. **去抖/滤波**（手的坐标会抖，需要滤波 + 松手检测）

**电气注意**：I²C 必须**外部上拉**。如果板子 J6 附近没焊上拉电阻，
可以用 FPGA 内部弱上拉兜底，但只能低速跑、可靠性差，建议外挂 2 个 4.7k 到 3.3V。

## 六、预期现象

### ADC / 音符

| 输入电压 | `adcvalue` | 音符号 | MIDI |
|---------|-----------|--------|------|
| 0 V | 0 | 48 | C3 |
| 1.65 V | ~3380 | 60 | C4 |
| 3.3 V | ~6758 | 72 | C5 |

测试方法：把 **AA20** 用杜邦线在 **GND** 和 **3.3V** 之间切换，看音高变化。
（接按键时：按下 = 3.3V = 出声，松开 = 0V = 停止。）

> ★ **按键极性（已实测定论，别再"按模块说明"猜）**：本按键模块是
> **松开 = 0V、按下 = 3.3V（高有效）**。所以：
> - `top.v` 里 `button_in` 例化必须用 `ACTIVE_LOW (1'b0)`
> - ADC 那条备用通路 `ADC_INVERT` 也用 `1'b0`（两处极性要一致）
>
> 如果写反成"低有效"，症状非常典型：**上电就一直响，按住按键反而没声音**
> （松开被当成按下 → gate=1 长鸣；按下被当成松开 → note_off 静音）。
> CST 里 `BTN` 的 `PULL_MODE=UP` 只是弱上拉兜底，按键模块松开时会把引脚拉到 0V，
> 弱上拉拉不动，所以空闲读数是 0。

### 音频

插耳机（或接扬声器）应能听到声音。按 **KEY0** 循环切换 5 档音色，
同时 8 个 LED 会显示当前档位号（`LEDs[2:0]`）。

| 档位 | 按住测试键听到的 | 松开后 |
|------|----------------|--------|
| 0 方波 | 持续的音（蜂鸣器感） | ≈335ms 收尾 |
| 1 锯齿（上电默认） | 持续的、明亮的音 | ≈335ms 收尾 |
| 2 三角 | 持续的、柔和的音 | ≈335ms 收尾 |
| 3 正弦 | 持续的、纯净的音 | ≈335ms 收尾 |
| **4 钢琴** | **"叮"一下后 5.4 秒内逐渐消失**（按住不放也会安静下来） | **立刻静音（≈1.3ms）** |

**混音台 / 效果器（2026-10-26 第三轮）**

- 网页下方「混音台 · 32 声部」：1–8 对应 8 个琴键，9–32 默认折叠。
- 每个通道有音量、失真、4 路发送量；把某个键的「回声/混响/合唱/相位」拉高，
  只有那个键会进对应效果器，而且**会自动打开对应全局效果器**。
- 4 个全局效果器都带开关和参数滑块；主失真、限幅、5 段 EQ 在混音台下面。
- **八度**在「演奏效果」卡片里（−2~+2），和板上 `KBD_UP/DN` 双向同步。
- **延音（松开后）**也在「演奏效果」卡片里：钢琴/古筝/木琴切过去默认关，
  颠琴/钟琴默认开 40（约 1 秒拖尾），手动可调到 127（约 21 秒）。它只对 one-shot 音色有效，
  切到持续音会自动关闭并禁用滑块；ADSR 的「延音电平 S」和它不是一回事。
- **32 声部齐奏/超锯齿**在效果器区：8 键 × 4 层 = 32 个振荡器，默认开、4 层、失谐 ≈1.56%、混合 ≈79%；
  主声部是第 1 层，另外 3 层是微失谐锯齿，共用包络/力度。想要纯 supersaw 就用锯齿音色 + 齐奏。
- **PWM 脉宽调制**：网页「PWM 脉宽调制」卡片，基础脉宽/速率/深度三根滑块；只作用在**方波**，
  寄存器 `0x2D`~`0x2F`。默认 128 / 3Hz / 96；动 PWM 会自动切到方波。
- **新增 FM 音色**：8 颠琴（ratio 2.0、短促电钢）、9 钟琴（ratio 3.5、明亮钟声），都是 one-shot，
  所以延音踏板对它们也有效。
- **监视器**：网页有波形/频谱**预览**（按当前参数估算）；HDMI 顶部波形区压缩出 80px，
  用真实 `mix_pcm` 的 4 段频谱画成 8 条。
- 效果尾音会在松手后继续响；如果听到长鸣，先查包络/效果反馈，不要直接加硬静音门。

> 完整寄存器/操作说明见 **[`web/README.md`](web/README.md)**。

### 显示

屏上应看到（顶部两行是状态栏，`TOP_H = 62`）：

```
y  0..27   一排声部方块随发声点亮 + 当前复音数 / 峰值复音数
y 30..59   ★ 键盘行：8 格音名（C4 D4 E4 F4 G4 A4 B4 C5），按下的格子变亮
y 62..479  波形区：中间一条基准线 + 绿色的音频波形
```

**键盘行怎么用**：没接键盘时 8 格都是暗的、显示音名；接上键盘后，
按哪个键哪一格就亮（亮青框 + 白字），接线对不对一眼就能看出来。

> 音名显示依赖 `lcd_draw` 的 `KBD_NOTE_LO / KBD_REVERSE`，这两个值
> 由顶层参数自动传入（`top.v` 里那份），**不需要改两处**。

## 七、常见问题

### ADC 相关

1. **读数一直是固定值**：多半是 `vsenctl` 没选对。`top.v` 里 `VSENCTL_VALUE = 3'b100`
   （对应 bus4），读不到就依次试 `3'b000`~`3'b111`。
2. **`chen` 通道使能**：`CHEN_VALUE = 7'b0000001`；读不到可改成 `7'b1111111` 试。
3. **0V 和 3.3V 变化方向相反**：把 `top.v` 最后一行改成 `assign LEDs = ~adc_data[11:4];`。
4. **ADC 引脚报错 "Can't find pad location"**：专用 ADC 脚（N10/N9/L10/M9）是
   `TYPE=DIO`，不能写 `IO_LOC`，工具会自动放置。

### 音频相关

| 现象 | 可能原因 |
|------|---------|
| 完全没声音 | `PA_EN` 极性 / 耳机没插好 / 蓝牙功放供电 |
| **上电就一直响，按下按键才停** | **按键极性反了**：`top.v` 里 `button_in` 的 `ACTIVE_LOW` 要设 `1'b0`（本模块是高有效） |
| 松手后拖尾很久 | 持续音档正常（释音 ≈ 335ms，`ADSR_REL`）；**钢琴档不该有拖尾**，若钢琴档也拖尾就是 `PIANO_REL` 没生效 |
| 钢琴档按住不衰减 | `PIANO_SUS` 必须为 `0`；`PIANO_DEC` 越大衰减越快（1 ≈ 5.4s） |
| 钢琴尾音不够长 | 抬高 `PIANO_RATE`（每 +1 时长翻倍；2 → 5.4s，3 → 10.7s） |
| 钢琴尾音怎么调都很短（1.3 秒左右） | 撞到 16 位包络的上限了：`env_rate = 0` 时最长只能衰减 1.34 秒，必须用 `PIANO_RATE > 0` |
| 钢琴档声音太单薄 | 钢琴档用的是纯正弦波，属于预期；想更厚需要改 `osc_voice.v` 叠泛音 |
| 有噪音不是音调 | PT8211 格式 / 采样率差太多 |
| 音调偏高 | 采样率 48828Hz 比 48k 高 1.7%，正常 |
| 只有一边声道响 | 左/右声道标志位 |

### LCD 相关

| 现象 | 原因 / 下一步 |
|------|--------------|
| 全黑但背光亮 | 时序不对 → 试对调 HSYNC/VSYNC |
| 画面滚动/撕裂 | 同步极性反了 → 把 `HSYNC_LOW`/`VSYNC_LOW` 改成 `1'b0` |
| 花屏/雪花 | 控制脚对应错 → 4 个球号两两对调 |
| 有画面但颜色怪 | RGB 数据线接法不同 → 调 `LCD_HD[n]` 顺序 |
| 背光不亮 | `LCD_BL` 极性反了 → 改成 `1'b0` |
| 画面偏/四周有黑边 | 消隐参数不匹配 → 按屏手册调 `H_FP/H_SYNC/H_BP/V_*` |
